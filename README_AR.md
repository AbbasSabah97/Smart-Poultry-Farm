# Smart Poultry Farm v1.1 — Seven Houses 3D

## التعديلات المطلوبة
- حذف بوابتي **Monitoring Gateway** و**Fleet Gateway** بالكامل من الحزمة ومن GitHub Actions وواجهة المستخدم. لا يوجد اتصال بالحساسات الحقيقية في هذا الإصدار؛ البيانات المعروضة **محاكاة فقط**.
- عرض سبع حضائر مجسمة معاً في منظور الموقع؛ يمكن الضغط على أي مبنى لتحديده وتحديث بياناته في **الشريط العلوي**.
- استبدال التخطيط الجانبي بشريط علوي لبيانات الحضيرة المختارة (الحرارة، الرطوبة، العلف، الماء، الغازات، العمر والإنذارات).
- نموذج تفصيلي للحضيرة المختارة عند الضغط على «دخول الحضيرة المختارة». ويوجد زر للعودة إلى عرض السبع.
- 150 دجاجة بيضاء ثابتة في النموذج التفصيلي المختار باستخدام مجسم `hen_tripo.glb` الذي قدمته؛ لا يوجد تحريك جسم/أقدام، مع توجيه الدجاج بجوار الجدران إلى داخل الحظيرة.
- حذف الجسيمات المتحركة على الوصلات من السايلو وخزان الماء. الأنابيب تبقى لأغراض التصميم، ويمكن لمستوى المعالف ومؤشرات الماء التغير رقمياً.
- أيقونة تطبيق Windows وأيقونة المتصفح على شكل وجه ديك من رسم SVG أصلي.

## طريقة الاستخدام
1. افتح التطبيق: سترى 7 حضائر ثلاثية الأبعاد في مخطط موقع واحد.
2. انقر على **أي مبنى** أو زر H01..H07 أعلى الشاشة: ستظهر بيانات الحضيرة المحددة أعلى المشهد.
3. اضغط «دخول الحضيرة المختارة» لرؤية التصميم الداخلي التفصيلي و150 دجاجة ثابتة.
4. اضغط «عرض الحضائر السبع» للعودة إلى الموقع بالكامل.
5. «المعالف والمشارب» و«المراوح والتبريد» يفتحان زوايا داخلية للحضيرة المحددة.
6. استخدم عجلة الفأرة للتقريب والسحب للدوران، ولا تتصل النسخة بأي أجهزة ميدانية.

## بناء Windows دون Unity
1. افتح المستودع في GitHub وارفع الملفات الجديدة.
2. شغّل Actions → Build Smart Poultry Farm for Windows.
3. بعد نجاح البناء نزّل Artifact باسم SmartPoultry-SevenHouses-Windows.
4. يمكن اختبار المتصفح محلياً بعد تثبيت Node.js: `npm install`, ثم `npm run dev`.

**تنبيه هندسي:** تصميم الموقع مبسط ثلاثياً ويستخدم نسخة تفصيلية واحدة يعاد توجيهها للمنظور الداخلي عند اختيار الحضيرة لتقليل استهلاك الذاكرة. كل واحدة من الحضائر السبع لها بيانات محاكاة مستقلة في `src/fleet.js`. لا يوجد في هذا الإصدار Gateway ولا تحكم PLC حقيقي. فحص الأداء داخل Windows وواقع اتجاه مجسم الدجاج المستورد يحتاج تشغيل النسخة المبنية على جهازك.
